## ১. প্রথমবার সেটআপ (৫ মিনিট)

1. TradingView → **Pine Editor** খুলুন → `liqudity_trap_trading.txt`-এর পুরো কোড কপি করে পেস্ট করুন → **Save** → **Add to chart**।
2. চার্ট টাইমফ্রেম **M5** (ডিফল্ট এই TF ধরে টিউন করা)।
3. ইন্ডিকেটর সেটিংস খুলুন (গিয়ার আইকন) → **General → Symbol profile** সেট করুন:

| আপনি ট্রেড করছেন | Symbol profile |
|---|---|
| EURUSD, GBPUSD, USDJPY ইত্যাদি | `FX majors` |
| XAUUSD (গোল্ড), XAGUSD | `Metals / XAU` |
| NAS100, US30, SPX500, GER40 | `Indices` |
| BTCUSDT, ETHUSDT | `Crypto` |
| নিজে হাতে টিউন করবেন | `Manual` |

> Profile নয়টা ATR-ভিত্তিক কনস্ট্যান্ট একসাথে বদলায় (pivot length, zone height, displacement, sweep memory ইত্যাদি)। **এগুলো শুরুর পয়েন্ট, চূড়ান্ত সত্য না** — পরে Strategy Tester দিয়ে ক্যালিব্রেট করবেন (সেকশন ১১)।

4. **Risk / TP / SL → Round-trip cost (ticks)** — আপনার ব্রোকারের স্প্রেড + কমিশন টিক-এ বসান। XAU M5-তে সাধারণত 20–30। এটা না দিলে চার্টের RR বাস্তবের চেয়ে ভালো দেখাবে।
5. **Volume confirmation** — crypto / index / futures হলে `Require relative volume` ON করুন। স্পট ফরেক্সে OFF-ই রাখুন (tick volume দুর্বল)।

## ৩. মেশিনের পাঁচটা স্টেজ — ট্রেডারের কাজ

```
idle → SWEPT → AT POI → SHIFTED·await retest → ACTIVE
```

| স্টেজ | চার্টে কী ঘটেছে | আপনার কাজ |
|---|---|---|
| **SWEPT** | একটা লিকুইডিটি লেভেল নেওয়া হয়েছে আর reclaim হয়েছে | কিছু না। শুধু নজর রাখুন |
| **AT POI** | দাম zone / HTF POI-তে এসেছে | চার্টে anchor বক্স দেখুন |
| **SHIFTED · await retest** | MSS/CHoCH হয়েছে, FVG lock হয়েছে | **এখানেই প্রস্তুত হন** — anchor বক্সের CE লাইনে লিমিট অর্ডার ভাবা যায় |
| **ACTIVE** | এন্ট্রি হয়েছে, ট্র্যাকার ট্রেড ধরছে | SL/TP ম্যানেজ করুন |
| **idle + reason** | সেটআপ মরে গেছে | Debug টেবিলে কারণ দেখুন |

> `fastShift` ON থাকলে (ডিফল্ট) sweep-এর পর displaced shift এলে POI স্টেজ **স্কিপ** করে সরাসরি SHIFTED-এ যায় — এটাই 2022 model। raid নিজেই POI।

## ৪. সিগন্যাল লেবেল পড়া

```
A+ · 72
◆ SB NY AM · CE A+          ← সোর্স
```

প্রথম লাইন = **tier · score**। দ্বিতীয় লাইন = কোন ইঞ্জিন:

| লেবেল | অর্থ | ওজন |
|---|---|---|
| `◆ SB …` | Silver Bullet উইন্ডো এন্ট্রি (CE বা edge) | সর্বোচ্চ |
| `◉ SETUP A/A+` | সাধারণ মেশিন এন্ট্রি | উচ্চ |
| `◬ TRAP LT-x` | লিকুইডিটি ট্র্যাপ | মাঝারি |
| `Demand 50% · CRT · TSoup · IB break · Doji rev · TL sweep · ◎ FEM` | ইঞ্জিন ক্যান্ডিডেট | নিম্ন |

**Tier:** C = খালি ট্রিগার · B = ট্রিগার + এক লেয়ার · **A = পুরো চেইন** · **A+ = A + HTF + session + strong raw sweep + সঠিক premium/discount**।
ডিফল্ট ফিল্টার `A and above` — B/C দেখাবেই না। এটা ইচ্ছাকৃত।

## ৫. এন্ট্রি / স্টপ / টার্গেট

সিগন্যাল বারে ৫টা লাইন আসে: **E · SL · TP1 · TP2 · TP3**।

- **E**-এর পাশে `RR 1.8 (plan, not promise)` — এটা **খরচ বাদ দেওয়া নিট RR** (costTicks যুক্ত করার পর)।
- `· engine fill = next open` লেখা থাকলে ট্র্যাকার পরের বারের ওপেনে ফিল ধরে — কারণ ক্লোজে অর্ডার বসানো যায় না।
- **TP1** = 1R → এখানে স্টপ break-even + বাফারে যায় (স্বয়ংক্রিয় হিসাব, আপনাকে ম্যানুয়ালি করতে হবে)।
- **TP2** = `rrMult` (ডিফল্ট 2R), কিন্তু মাঝে বিপরীত POI থাকলে সেখানেই ক্ল্যাম্প হয়।
- **TP3** = liquidity target (বিপরীত session H/L, PDH/PDL বা unspent POI)।

ট্রেড ক্লোজ হলে লাইনগুলো চার্ট থেকে **মুছে যায়** — পুরোনো প্ল্যান আর ঝুলে থাকবে না।

## ৬. রিস্ক গভর্নেন্স (নতুন, ডিফল্ট ON)

**Risk governance (per day):**
- `Max signals per day` = **4**
- `Stop after N losing trades` = **2**

লিমিট ছুঁলে ভার্ডিক্ট বলবে `NO · day closed — X signals, Y losses` এবং **কোনো সিগন্যাল আর ফায়ার করবে না**। দিনের বাউন্ডারিতে রিসেট।

> এটা ইন্ডিকেটরের নিজের গোনা, আপনার ব্রোকার অ্যাকাউন্টের না। ম্যানুয়ালি বেশি ট্রেড করলে ইন্ডিকেটর জানবে না।

আরও দুটো রিস্ক গেট আগে থেকেই আছে:
- **Max risk (ATR ×) = 1.5** — স্টপ এর চেয়ে চওড়া হলে সিগন্যাল বাতিল ("you are late")।
- **Min RR to TP2 = 1.5** — খরচ বাদে এত না পেলে ট্রেড নেই।

## ৭. Silver Bullet উইন্ডো — বাংলাদেশ সময়

উইন্ডো তিনটা **নিউ ইয়র্ক সময়ে** সেট করা। বাংলাদেশ (UTC+6) সময়ে:

| উইন্ডো | NY | বাংলাদেশ (গ্রীষ্ম / EDT) | বাংলাদেশ (শীত / EST) |
|---|---|---|---|
| London open | 03:00–04:00 | **13:00–14:00** | 14:00–15:00 |
| **NY AM (প্রধান)** | 10:00–11:00 | **20:00–21:00** | 21:00–22:00 |
| NY PM | 14:00–15:00 | **00:00–01:00** | 01:00–02:00 |

- NY AM-এর ওজন সবচেয়ে বেশি, London সবচেয়ে কড়া (min sweep quality 3)।
- উইন্ডোর ১৫ মিনিট আগে থেকেই সেটআপ arm হতে পারে, কিন্তু **এন্ট্রি উইন্ডোর ভেতরেই**।
- উইন্ডো বন্ধ হলে unfilled SB সেটআপ মারা যায়, আর TP1 না লাগলে ট্রেড টাইম-এক্সিট হয়।
- প্রতি উইন্ডোতে প্রতি দিকে **একটাই** SB এন্ট্রি।

শুধু SB ট্রেড করতে চাইলে: `◆ Silver Bullet — entry → SB-only mode` ON।

## ৮. অ্যালার্ট সেটআপ

   **Trigger: `Once per bar close`** — অন্য কিছু দিলে ভুল হবে, ইঞ্জিন শুধু ক্লোজড বারে কাজ করে।

## ৯. চার্ট পরিষ্কার রাখা — Focus mode

`UI / style → Focus mode` **ডিফল্ট ON**। দামের **৪ ATR**-এর বাইরের সব zone / FVG বক্স অদৃশ্য হয়ে যায় (ডিলিট হয় না — ইঞ্জিনে আগের মতোই কাজ করে, শুধু চোখের সামনে থাকে না)।

- খুব খালি লাগলে `Focus distance` বাড়ান (6–8)।
- সব দেখতে চাইলে Focus mode OFF (v3.3-এর মতো, তবে চার্ট ঘিঞ্জি হবে)।
- আরও কমাতে: `Show zones` / `Draw live chart-TF FVGs` / `Rejection blocks` OFF করুন।

v3.4-এ **premium/discount শেড, OTE বক্স আর wick-cluster pool লাইন সরানো হয়েছে** (টোকেন বাজেট)। এদের **হিসাব আগের মতোই চলছে** — Range pos সারিতে premium/discount পড়ুন, OTE ফ্ল্যাগ ওখানেই দেখায়।

## ১১. ক্যালিব্রেশন — যা এখনো আপনার কাজ

**এখন পর্যন্ত `minScore 50`, `minRR 1.5`, `maxRiskAtr 1.5`, ডেইলি লিমিট আর চারটা profile — সবই যুক্তি দিয়ে বসানো ডিফল্ট, মাপা নাম্বার না।**

1. `python scripts/mktwin.py` চালান → `liqudity_trap_strategy.txt` তৈরি হবে (ইন্ডিকেটর থেকেই জেনারেট, detection কোড হুবহু এক)।
2. সেটা Pine Editor-এ পেস্ট করে চার্টে দিন → **Strategy Tester** খুলুন।
3. `minScore = 0`, `tierMode = All` দিয়ে ৬ মাসের M5 চালান → জেতা ট্রেডের স্কোর ডিস্ট্রিবিউশন দেখুন।
4. জেতা ট্রেডগুলোর **৪০তম পার্সেন্টাইলে** `minScore` বসান — গোল নাম্বারে না।
5. `fastShift` on/off আর `armGrace` 0/3 — চারটা কম্বিনেশন চালিয়ে সিম্বল অনুযায়ী বাছুন।
6. তারপর `tierMode` আর `sbMinTier` ঠিক করুন।

> ইন্ডিকেটর বদলালে টুইন **আবার জেনারেট** করুন। টুইন কখনো হাতে এডিট করবেন না।

## ১৩. যা এই টুল **নয়**

- অটো ট্রেডিং সিস্টেম না — অর্ডার আপনি দেবেন।
- win-rate প্রেডিক্টর না — স্কোর মানে **ন্যারেটিভ alignment**, সম্ভাবনা না।
- নিউজ ক্যালেন্ডার না — volatility উইন্ডোগুলো **ফিক্সড ঘড়ি**, সপ্তাহ অনুযায়ী নিজে এডিট করুন।
- ব্যাকটেস্ট না — ড্যাশবোর্ড/ডিবাগের কাউন্টার একটা **স্যাম্পল**, একসাথে একটাই ট্রেড ট্র্যাক হয়।

সব সিগন্যাল **ক্লোজড বারে** হিসাব হয়। রিপেইন্ট নেই। লাইভে যাওয়ার আগে নিজে ব্যাকটেস্ট করুন।

## ১৪. দ্রুত রেফারেন্স — রোজকার রুটিন

1. চার্ট খুলুন → Symbol profile ঠিক আছে কিনা দেখুন।
2. **Bias** সারি দেখুন — আজ কোন দিকে খেলবেন, একদিকই।
3. **Verdict** সারি দেখুন — কী আটকাচ্ছে।
4. **Setup L/S** সারি `SHIFTED·await retest` হলে চার্টের anchor বক্স + CE লাইন দেখুন।
5. সিগন্যাল লেবেল এলে tier ≥ A আর নিট RR ≥ 1.5 কিনা দেখে অর্ডার দিন।
6. TP1-এ স্টপ BE-তে তুলুন।
7. দিনের শেষে জার্নাল লাইনগুলো স্প্রেডশিটে ঢালুন।
8. `day closed` এলে ল্যাপটপ বন্ধ।
