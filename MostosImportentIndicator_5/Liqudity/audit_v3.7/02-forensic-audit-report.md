## B. Confirmed defects (code evidence আছে)

### D1 — চারটা engine signal নিজস্ব stop ছাড়া ship হয় · **P1**

- **লাইন:** stop selection chain 4558–4561; fallback 4570–4573; engine list 4495।
- **Root cause:** `sigHCrtLong/Short`, `sigHTbsLong/Short` (HTF CRT / Turtle soup), `sig3Long/Short` (inside bar), `sig4Long/Short` (doji) — এদের কোনো `sl*` variable নেই (grep: `slHCrt|slHTbs|sl3|sl4` → 0 hit)। `selSLLong` na হলে `fallbackL = min(low, low[1]) - SL_PAD_ATR*atr`।
- **Reproduce:** M5 chart, HTF=60 turtle soup fires (HTF candle 60 মিনিটে sweep করে reclaim করেছে)। Stop বসে শেষ দুটো M5 bar-এর নিচে — HTF sweep wick থেকে অনেক উপরে। Doji reversal-এ stop raid হওয়া level (`lastSup`) এর নিচে না বসে dojir নিচে বসে।
- **Impact:** structure-less stop → run হয়; risk cap (1.5 ATR) ছোট stop-কে pass করে দেয়, তাই "ঠিক আছে" মনে হয়। Counter-এ এই trade-গুলো loss হিসেবে পড়ে।
- **Fix:** চারটা stop var যোগ: HTF TBS → HTF candle-এর `low[1]`/`high[1]` tuple-এ export করে ± pad; HTF CRT → candle-1 wick; IB → `_ibLow`/`_mLow` mid; Doji → `lastSup - pad` / `lastRes + pad`। Chain-এ যোগ। খরচ ~80–100 token।
- **Regression:** এই চারটা signal-এর SL distance আগে/পরে তুলনা; অন্য pathway-র SL অপরিবর্তিত।

### D2 — Weak-body প্রথম close break latch খেয়ে ফেলে, পরের displaced BOS হারায় · **P1**

- **লাইন:** latch 1863–1868 (`resBroken := brokeUp and confirmed`); structure engine body gate 1890 (`body >= structDisp * atr`); external latch 1941–1944।
- **Root cause:** latch body-blind, engine body-aware। 0.2-ATR body-র close > `lastRes` → `resBroken = true`, কিন্তু `f_structure` ওই bar ignore করে। পরের bar 1.5-ATR body দিয়ে উপরে গেলে `brokeUp` আর true হয় না (`not resBroken`)। BOS কখনো register হয় না যতক্ষণ নতুন pivot না আসে।
- **Reproduce:** XAU M5, resistance 4300। Bar A close 4300.2 (body 0.3 ATR)। Bar B close 4304 (body 1.6 ATR)। Chart-এ BOS chip নেই, `regEBosUp` false → regime TRENDING হয় না, demand zone ★HP পায় না (2909 `resBrkBar` A-তে, zone B+1-এ হলে `bs` true হতে পারে—সেটা accidental)।
- **Impact:** BOS under-count → regime CHOP/RANGING বেশি, `ctx` structure points কম, LT-1 `brokeUp` weak bar-এ arm হয়, strong bar-এ না। prior review (v3.6) এ deferred #4।
- **Fix (দুটো option):** (a) latch শুধু `body >= structDisp*atr` হলে — কিন্তু তখন weak close ভেদ করার পর `sslRecl` multi-bar sweep (`supBroken` লাগে) ভাঙে; (b) দুই latch: `resBroken` (any close, sweep/reclaim logic-এর জন্য) + `resBosDone` (displaced close, structure-র জন্য)। (b) নিরাপদ, ~40 token। **এটা structure engine-এর behaviour বদলায় — আলাদা regression লাগবে।**

## D. Design observations (bug নয়, কিন্তু ফল বদলায়)

1. **Ordinary machine = reversal-only।** `shiftSrc` default external CHoCH/MSS → long শুধু external bearish structure থেকে। Clean LTF uptrend-এ pullback-sweep → BOS continuation কখনো machine entry দেয় না। Model D নেই (রিপোর্ট 03)।
2. **"Valid" swing sweep সস্তা** (1535: `firm` = close ≥ level + 0.125 ATR **OR** pen ≥ 0.25 ATR)। 5-bar pivot-এর প্রতি poke-ই arm করে; `[SETUP] Armed` alert noise।
3. **Machine tier floor A** (4413) — tier filter machine-এ কাজ করে না; শুধু `minScore` আর 18B গেট।
4. **Engine candidate Tier A = sweep in play লাগে** (3531 `liq >= 10`)। Continuation signal (IB, CRT, LT-1) প্রায় কখনো A পায় না → default-এ কার্যত বন্ধ। `tierMode = "B and above"` lever।
5. **`oneDir`**: long AT POI = short 15–35 bar block।
6. **OB** শুধু bar[2]; structure break-এর সাথে যুক্ত নয়।
7. **Score correlated:** MSS (12) ⇒ sweep in play (10) by definition; raw≥3 (5) + SB quality (2–3); `execLong` conf (5) + `f_ltScore` strongRej (15)। রিপোর্ট 04 §8।
