### FIX-A1 stop anchors

- **HTF CRT:** HTF function tuple-এ `low[2]` / `high[2]` export (sweep candle, displacement candle-এর আগেরটা) → `slHCrtLong = hCrtLo − SL_PAD_ATR × atr`।
- **HTF TBS:** `low[1]` / `high[1]` (reclaim candle নিজে) → `slHTbsLong/Short`।
- **Inside bar:** `(_ibLow + _mLow) / 2 − pad` (IB low আর mother low-এর মাঝখানে), function tuple-এ ফেরত।
- **Doji:** `min(lastSup, lowest(low, DOJI_WINDOW)) − pad` — raid করা level **এবং** raid wick দুটোই cover করে (audit-এ শুধু level বলা ছিল; wick যোগ করা হয়েছে, D5-এর একই যুক্তি)।
- Chain order: MC → FEM → SD → CRT → TBS → **HCRT → HTBS → IB → Doji** → TL → LT। Pad = chart-TF ATR (HTF ATR না)।

### FIX-A2 দুই latch

- পুরনো `resBroken/supBroken` (any close) — sweep, reclaim, `resBrkBar`, LT-1, IB arm, zone ★HP: **সব অপরিবর্তিত**।
- নতুন `resBosDone/supBosDone`: শুধু `body >= structDisp × atr` close-এ latch হয়; pivot reset-এ দুটোই reset।
- `f_structure(brokeUpS, brokeDnS)` এবং external `f_structure(eBrokeUpS, eBrokeDnS)` এখন নতুন latch পড়ে।
- **Side effect (ইচ্ছাকৃত):** weak close ভেদ করার পর N bar পরে displaced bar এলেও BOS হবে (নতুন pivot না আসা পর্যন্ত)। Cap দেওয়া হয়নি — regression-এ দেখুন late-BOS কত।
