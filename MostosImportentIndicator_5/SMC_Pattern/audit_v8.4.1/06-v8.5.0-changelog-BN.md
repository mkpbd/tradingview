## Default behaviour বদল (user-visible)

1. Trend আর 20 bar-এ RANGE হয় না (40)। Panel "LTF structure" বেশি সময় BULLISH/BEARISH দেখাবে; CHoCH বেশি, "BOS" কম।
2. POOL label কম — এক retest wick আর POOL নয়। M10 (POOL form), M41/M45/M54/CISD arming কমবে।
3. M41/M46/M68 FVG-reaction signal **নতুন** আসবে (আগে dead)।
4. CHoCH-এর পরের M05/M15/M62/M72 signal নতুন আসবে।
5. Counter-HTF signal score +1 বেশি (triple penalty → double)। `reject code` 5 → 0 shift কিছু।
6. CONFIRMED trigger কড়া (body ≥ 0.4, 0.1 ATR beyond, trade-direction candle) → zone-module signal কমবে, late poke বাদ।
7. Continuation module (M02 M05 M08 M15 M33 M36 M42 M51 M73) deep premium/discount-এ reject code 2।
8. TP1 "FAR" নতুন provenance (panel/tooltip orange) — আগে এগুলো reject হতো।
9. Path check: entry-TP1 মাঝে unmitigated opposing FVG → STRICT reject; POOL/PD/PW/SES level → WARN −1।
10. Score: discount+OTE+NY-open সর্বোচ্চ +2 (আগে +3); session point forex-এ 0 (filter on) → **score গড়ে 1–2 কম**। `i_minScore 8` একই রাখা হয়েছে; signal count কমলে 7-এ নামিয়ে OOS-এ দেখুন (05 §4)।
11. M73 A+ কম হবে (tier 3); M39 sweep-origin form A হবে।
12. Sweep-based SL (M10, zone-less sweep) wick-এর নিচে — কিছু M10 R:R < 2 হয়ে reject code 4।
