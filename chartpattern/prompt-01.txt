## Technical Requirements

### Pine Script Version

* Use Pine Script v6 only.
* Follow TradingView best practices.
* Ensure code compiles without warnings or errors.

### Repainting Rules

The indicator must:

* Never repaint.
* Never use future-looking data.
* Never use lookahead mode.
* Confirm signals only after candle close.
* Use `barstate.isconfirmed` where necessary.

### Pattern Detection Engine

Use a hybrid approach combining:

* Pivot highs/lows
* ZigZag logic
* Swing structure analysis
* Trendline convergence/divergence
* Volume confirmation
* ATR normalization
* Volatility filters

Patterns must adapt dynamically to:

* Different market conditions
* Different timeframes
* Different instrument volatility

## Validation Rules

A pattern is valid only if:

* Minimum swing count is satisfied.
* Neckline is respected.
* Geometric ratios fall within configurable tolerances.
* Volume confirms breakout.
* Breakout candle closes beyond confirmation level.
* ATR-adjusted noise filter passes.
* Pattern size exceeds minimum threshold.

Provide user inputs for:

* Tolerance percentage
* Minimum bars per pattern
* Maximum bars per pattern
* Volume multiplier
* ATR filter strength
* Breakout confirmation candles
* Pivot sensitivity
